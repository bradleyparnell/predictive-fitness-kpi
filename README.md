# Predictive Fitness KPI Dashboard

Live marketing KPI dashboard for TriDot and RunDot.

## Setup

1. Go to **Settings → Secrets and variables → Actions** in this repo
2. Add a secret named `HUBSPOT_API_KEY` with your HubSpot private app token
3. Enable GitHub Pages: **Settings → Pages → Source: Deploy from branch → Branch: main → Folder: /docs**

The dashboard will auto-refresh every 6 hours.
